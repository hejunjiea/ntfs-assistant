NTFS助手 安装使用说明
================================================================

一、这个软件是做什么的
----------------------------------------------------------------
macOS 系统默认只能“只读”打开 NTFS 格式的硬盘（Windows 电脑常用的
移动硬盘、U 盘多为 NTFS），无法复制、删除、修改里面的文件。

NTFS助手 可以接管 NTFS 硬盘，让它变成可读写，并提供文件管理和
传输队列，用来拷贝大文件时能看到真实进度。


二、系统要求
----------------------------------------------------------------
1. macOS 14.0 或更高版本
2. Intel 芯片或 Apple 芯片（M1/M2/M3 等）的 Mac 都可以
3. 需要额外安装两个运行环境（见下面第 1 步）


三、安装（共三步）
----------------------------------------------------------------

第 1 步：解压并放行（重要）

把收到的 NTFS助手.zip 解压，得到 NTFS助手.app 和本说明文件。

直接双击 App 时，系统可能提示“无法验证开发者”或“App 已损坏”。
这是因为软件没有购买苹果开发者证书，属于正常现象，按下面任一方法
放行即可：

方法一（推荐，最省事）：
打开“终端”，输入下面命令并回车（注意路径要和实际位置一致）：

    xattr -dr com.apple.quarantine "/Applications/NTFS助手.app"

方法二（不敲命令）：
双击 App，看到拦截提示后点“完成”，然后打开
“系统设置 - 隐私与安全性”，向下滚动找到关于 NTFS助手 的提示，
点击“仍要打开”，再输入开机密码确认。


第 2 步：按软件内的向导配置运行环境

NTFS助手需要 ntfs-3g 和 macFUSE 两个免费组件才能读写 NTFS 磁盘。

软件已经内置了完整的安装教程，不需要自己查资料。打开 App 后，
如果环境没有配置好，主窗口会直接显示“首次使用：配置运行环境”
页面，里面按 1、2、3、4 四步依次说明：

  第 1 步  安装 Homebrew（系统自带的软件包管理器，只需装一次）
  第 2 步  安装 macFUSE（装完必须重启电脑才生效）
  第 3 步  安装 ntfs-3g（真正负责读写 NTFS 的驱动）
  第 4 步  重启电脑，并在系统设置里允许 macFUSE 扩展

每一步都配好了需要执行的命令，点右侧“复制”按钮复制，
再点页面下方“打开终端”，在终端窗口里粘贴回车即可执行。
全部装完后点“重新检测”，三个组件都变成绿色对勾就配置完成了。

提示：如果当时点了“稍后配置”，重新打开软件即可再次看到向导；
也可以按 Command + 逗号 打开设置，查看各组件的检测结果。


第 3 步：放进应用程序文件夹

把 NTFS助手.app 拖到“应用程序”文件夹，以后从启动台打开即可。


四、首次使用
----------------------------------------------------------------
1. 插上 NTFS 硬盘，软件左侧会出现该硬盘，状态显示“只读挂载”
2. 点击左侧顶部“一键挂载”，或右键点击硬盘选“接管为读写模式”
3. 系统会弹出管理员授权窗口，输入开机密码允许
4. 挂载成功后硬盘名称旁出现绿色对勾，右侧显示文件列表
5. 如果某一行的状态一直是“只读挂载”，可以右键该盘单独重试


五、常用操作
----------------------------------------------------------------
【文件操作】
- 双击文件夹：进入；双击文件：用默认程序打开
- 拖文件进窗口：自动复制到当前目录，同名文件会自动加序号
- 拖文件出窗口：可拖到桌面或访达
- 右键菜单：删除、重命名、复制、在访达中显示

【快捷键】（先点一下文件列表，让焦点在列表上）
- Command + C    复制选中项
- Command + V    粘贴到当前目录
- Command + 删除 删除选中项（会二次确认）
- 空格           快速预览（Quick Look）

【多选批量】
按住 Command 点选或按住 Shift 连选，可批量删除、批量复制，
右键菜单会显示“删除 3 项”这样的数量提示。

【查找与排序】
右上角搜索框可实时过滤当前目录的文件。
点搜索框右边的“...”按钮，可切换排序方式（名称/大小/日期/类型）
和“显示隐藏文件”。

【传输队列】
多选或一次拖入多个文件时会自动排队，窗口顶部显示队列面板，
可以看到每一项的进度、速度、剩余时间，也可以单独取消，
或点“全部取消”。复制前会自动检查目标空间是否足够。

【菜单栏】
屏幕右上角菜单栏有硬盘图标，点开可直接挂载/弹出硬盘，
不用打开主窗口。

【设置】
按 Command + 逗号 打开设置，可以：
- 查看运行环境检测结果（ntfs-3g、macFUSE、SIP 状态）
- 开启“登录时自动启动”


六、常见问题
----------------------------------------------------------------
问：点挂载后提示“操作失败或管理员授权被取消”？
答：多数是运行环境没装好。重新打开软件，主窗口会显示
    “首次使用：配置运行环境”向导，按里面的 1 到 4 步重新配置；
    也可以在设置页查看三个组件的检测状态。

问：挂载后看不到文件，或者硬盘名没变绿？
答：可能是杀毒软件或系统自带的 fsck 检查占用了磁盘。
    右键该盘选“卸载并恢复只读”，然后再点“接管为读写模式”重试。

问：提示“空间不足”无法复制？
答：目标硬盘剩余空间不足。NTFS助手会预留 5% 余量，
    避免写满后文件系统出错。

问：复制到一半我点了取消，会不会留下坏文件？
答：不会。取消后会自动删除复制了一半的临时文件。

问：为什么每次挂载都要输密码？
答：接管磁盘需要管理员权限，这是 macOS 的安全机制，无法跳过。

问：能不能不要“无法验证开发者”的提示？
答：需要购买苹果开发者证书（每年 99 美元）做签名和公证。
    目前个人版本无法免除此提示，放行一次以后就不会再提示。


七、卸载
----------------------------------------------------------------
1. 先把硬盘恢复正常只读：
   在软件左侧右键硬盘，选“卸载并恢复只读”，然后再拔盘。
   注意：不要在读写挂载状态下直接拔硬盘，可能导致数据损坏。

2. 退出软件，把“应用程序”里的 NTFS助手.app 拖到废纸篓。

3. 可选：如果不再需要 NTFS 读写功能，可卸载运行环境：

    brew uninstall ntfs-3g-mac
    brew uninstall --cask macfuse


八、注意事项
----------------------------------------------------------------
- 重要数据请提前备份。任何第三方 NTFS 驱动都无法保证 100% 兼容，
  尤其是磁盘存在坏道或曾经异常断电的情况。
- 传输大文件时请不要强制关机或拔出硬盘。
- 本软件会修改磁盘挂载方式，使用前请确认磁盘内数据已有备份。
